BufANN is derived from DiskANN and retains inherited components that the current
runtime and benchmark path still depend on. DiskANN itself builds upon NSG.

This repository keeps the original upstream MIT licensing model and preserves
the NSG attribution below.

Optional IVF centroid-router dependency
---------------------------------------
The IVF router uses a locally modified, vendored version of hnswlib v0.8.0 and
an externally fetched, unmodified v0.8.0 comparison implementation, from
https://github.com/nmslib/hnswlib, under the Apache License 2.0.
See dependencies/hnswlib/README.md for provenance, modifications and build configuration,
and dependencies/hnswlib/LICENSE for the complete upstream license. This optional
dependency does not change the licenses of existing BufANN/DiskANN sources.
